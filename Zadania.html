Zadanie 3: Inteligentny Segregator

Napisz funkcję segreguj, która przyjmuje listę słów. Użyj pętli for, aby podzielić słowa na dwie listy (dłuższe niż 5 znaków i krótsze/równe). Zwróć obie listy na końcu funkcji.

Pokaż przykładowe rozwiązanie 
def segreguj(lista_slow: list):
    dlugie = []
    krotkie = []
    
    for slowo in lista_slow:
        if len(slowo) > 5:
            dlugie.append(slowo)
        else:
            krotkie.append(slowo)
            
    return dlugie, krotkie

Zadanie: Raport HR

Napisz funkcję raport_HR(pracownicy: list).
baza = [" jAn#KOWALSKI#5000,50 ", " aNNA#noWAK#6000,00 ", "PIOTR#Zyla#4500,00"]

Zadania do zrobienia:
1. Utwórz dwie listy: kobiety i mezczyzni.
2. Pętlą podziel dane po '#'.
3. Wyczyść imię i nazwisko (spacje, duże litery).
4. Wyczyść pensję i zrób z niej float (zamień przecinek na kropkę).
5. Sprawdź płeć (ostatnia litera 'a').
6. Zbuduj f-string: "Jan Kowalski zarabia 5000.5 PLN" i dodaj do odpowiedniej listy.
7. Zwróć obie listy i wypisz na ekranie.

Pokaż przykładowe rozwiązanie 
def raport_HR(pracownicy: list):
    kobiety = []
    mezczyzni = []
    
    for osoba in pracownicy:
        imie_sur, nazwisko_sur, pensja_sur = osoba.split('#')
        
        imie = imie_sur.strip().capitalize()
        nazwisko = nazwisko_sur.strip().capitalize()
        pensja = float(pensja_sur.strip().replace(',', '.'))
        
        wizytowka = f"{imie} {nazwisko} zarabia {pensja} PLN"
        
        if imie[-1].lower() == 'a':
            kobiety.append(wizytowka)
        else:
            mezczyzni.append(wizytowka)
            
    return kobiety, mezczyzni

baza = ["  jAn#KOWALSKI#5000,50 ", "  aNNA#noWAK#6000,00  ", "PIOTR#Zyla#4500,00"]
lista_k, lista_m = raport_HR(baza)

print("--- RAPORT KOBIET ---")
for k in lista_k: print(k)

print("\n--- RAPORT MĘŻCZYZN ---")
for m in lista_m: print(m)

Oto wyzwania sprawdzające odczyt i zapis danych z dysku oraz weryfikację tego, co wpisuje użytkownik.

Zadanie 1: Natrętny strażnik (while True)

Napisz funkcję pobierz_wiek(). Wewnątrz stwórz nieskończoną pętlę while True, która zapyta użytkownika o wiek.
Użyj metody tekstowej .isdigit(), aby sprawdzić, czy wpisano same cyfry. Jeśli tak – przerób tekst na int i użyj return, aby zwrócić wiek. Jeśli nie – wypisz "Błąd! Wpisz samą liczbę." i pozwól pętli zapytać ponownie.

Pokaż przykładowe rozwiązanie 
def pobierz_wiek():
    while True:
        wiek_str = input("Podaj swój wiek: ").strip()
        
        if wiek_str.isdigit():
            return int(wiek_str)
        else:
            print("Błąd! Wpisz samą liczbę.")

moj_wiek = pobierz_wiek()
print(f"Twój wiek to {moj_wiek} lat.")

Zadanie 3: Wykrywacz błędnych współrzędnych

Masz plik punkty.txt, w którym każda linia to współrzędne rozdzielone przecinkiem (np. 15,45).
Użyj with open (tryb 'r'), pętli for oraz enumerate(). W pętli pozbądź się znaków nowej linii (.strip()) i podziel linię w miejscu przecinka (.split(',')). Jeśli otrzymana w ten sposób lista ma dokładnie 2 elementy, wypisz "Linia [numer]: OK", w przeciwnym razie "Linia [numer]: BŁĄD".

Pokaż przykładowe rozwiązanie 
# Zakładamy, że plik punkty.txt istnieje
with open('punkty.txt', 'r', encoding='utf-8') as plik:
    for numer, linia in enumerate(plik):
        
        # strip() czyści z \n, a split() dzieli na listę
        elementy = linia.strip().split(',')
        
        if len(elementy) == 2:
            print(f"Linia {numer}: OK (X={elementy[0]}, Y={elementy[1]})")
        else:
            print(f"Linia {numer}: BŁĄD DANYCH!")

Zadanie 4: Ekstremalne pomiary

Napisz funkcję oblicz_skrajnosci(lista_pomiarow). Funkcja ma przyjąć listę liczb. Wewnątrz użyj wbudowanych funkcji matematycznych, aby znaleźć najmniejszą i największą wartość, a następnie zwróć je obie. Wywołaj funkcję dla listy [10.5, 45.2, 8.9, 99.1, 4.3] i wypisz wynik.

Pokaż przykładowe rozwiązanie 
def oblicz_skrajnosci(lista_pomiarow):
    najmniejszy = min(lista_pomiarow)
    najwiekszy = max(lista_pomiarow)
    return najmniejszy, najwiekszy

wyniki = [10.5, 45.2, 8.9, 99.1, 4.3]

# Rozpakowujemy zwrócone wartości
min_temp, max_temp = oblicz_skrajnosci(wyniki)
print(f"Skrajne temperatury: od {min_temp} do {max_temp} stopni.")
